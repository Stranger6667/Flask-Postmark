# Security Policy

## Supported Versions

Security fixes go to the latest release of Flask-Postmark only.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public GitHub issues.

Report them privately via [GitHub private vulnerability reporting](https://github.com/Stranger6667/Flask-Postmark/security/advisories/new).
Include a description of the vulnerability, the steps to reproduce it, and the affected Flask-Postmark version.
A suggested fix or mitigation is welcome.

Fixes are released as regular versions and noted in the [changelog](CHANGELOG.md).
